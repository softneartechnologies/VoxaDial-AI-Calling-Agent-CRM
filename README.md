# VoxaDial — AI Calling Agent + CRM

AI voice agents that call, qualify and book leads, with a built-in CRM.

| Folder | Status |
|---|---|
| `frontend/` | ✅ React 19 + TypeScript + Vite + Tailwind. Marketing site + full dashboard (runs on demo data) |
| `backend/` | ⏳ Coming next: Node + PostgreSQL + telephony / STT / LLM / TTS |

## Quick start
```bash
cd frontend
npm install
npm run dev   # http://localhost:5173
```
See [`frontend/README.md`](frontend/README.md) for screens, project structure and the API contract the backend must implement.
